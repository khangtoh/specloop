# specloop 0.7.0

- Short CLI names: `list`, `audit`, `prio spec`, and `prio task`. All previous
  aliases remain supported.
- Native response menu: `$specloop` in Codex, `/specloop` in Claude project
  installs, and `/specloop:specloop` in Claude marketplace installs. Append an
  action to execute it. The menu includes the existing layout/group commands.
- Shared agent workflows for setup, adoption, audits, and autonomous execution.
  Bare skill invocation only shows the menu; plain chat `specloop` still runs
  autonomously and bare shell `specloop` still runs preflight.
- Claude/Codex onboarding and safe asset refresh with decision-reconciliation
  hooks. Exact shipped 0.5.0/0.6.0 assets can refresh; customized assets remain
  protected. Installed hooks require runtime trust/activation.
- Includes 0.6.0's grouped phase layouts, layout recommendations, migration,
  and correct aggregate counts and task targeting across sub-spec files.

Upgrade the npm package, then preview `specloop refresh --agent both`; apply
recognized updates with `specloop refresh --agent both --apply`. Restart the
agent to load updated skills. Review reported custom files for manual merging.

Verification: the combined suite and packaged onboarding pass. Native Codex
menu/list behavior has been observed. Live Claude menu verification and the
full reconciliation-hook runtime acceptance matrix remain open in the specs.
