# specloop 0.8.0

- Inline argument hints: Claude Code now previews each skill's arguments as you
  type, for example `/specloop  [loop|status|list · prio spec|prio task · …] [args]`,
  `/prio-spec  <NN> <pos>` and `/list-spec  [all|done|undone]`. Codex copies keep
  the hint under `metadata:` so they remain valid Agent Skills.
- Existing installs refresh cleanly: the 0.7.0 skill files are recognized, so
  `specloop refresh --agent both --apply` updates them without a manual merge.
  Customized skills stay protected.
- Releases are now driven by `VERSION`: a change on `main` verifies, packs,
  publishes to npm and tags through CI. For maintainers, `bun run release` only
  bumps the version, and `scripts/set-npm-token.sh` stores the publish token
  with the GitHub CLI.

Upgrade the npm package, then preview `specloop refresh --agent both` and apply
it with `--apply`. Restart the agent to load the updated skills.
